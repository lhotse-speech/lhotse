# Security Policy

## Supported versions

Security fixes are released for the latest version of Lhotse only. Please upgrade to the newest release on PyPI before reporting.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Instead, report them privately through GitHub:
[**Report a vulnerability**](https://github.com/lhotse-speech/lhotse/security/advisories/new)
(Security tab → Advisories → "Report a vulnerability").

Please include:

- the affected Lhotse version(s) and the function, recipe, or CLI command involved,
- a description of the issue and its impact,
- steps or a minimal proof of concept to reproduce it.

We will acknowledge your report, keep you updated as we work on a fix, and credit you in the published advisory and release notes unless you prefer otherwise. Once a fix is released, we publish a GitHub Security Advisory and request a CVE where appropriate.
